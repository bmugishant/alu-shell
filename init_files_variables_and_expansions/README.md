# Shell variables and expansions

0-alias creates the requested ls alias.
1-hello_you greets the current user.
2-path appends /action to PATH.
3-paths counts nonempty PATH directories.
4-global_variables lists environment variables.
5-local_variables lists shell variables and functions.
6-create_local_variable creates a local variable.
7-create_global_variable exports a variable.
8-true_knowledge adds 128.
9-divide_and_rule divides two values.
10-love_exponent_breath calculates a power.
11-binary_to_decimal converts binary to decimal.
12-combinations prints two-letter combinations except oo.
13-print_float prints two decimal places.
14-decimal_to_hexadecimal converts decimal to hexadecimal.
15-rot13 transforms text using ROT13.
16-odd prints alternating input lines.
17-water_and_stir adds values in the specified bases.
